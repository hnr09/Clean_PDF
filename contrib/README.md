# 학습 자료 수집 설정 (내 Google Drive에 모으기)

웹 페이지 사용자가 **직접 동의하고 "학습에 기여하기"를 누른 쪽만**
원본 이미지 · 결과(수정 포함) · 지운 영역이 내 Google Drive의 `CleanPDF_학습자료` 폴더에 저장됩니다.
특히 사용자가 ✏️ 수정 화면에서 되살리거나 지운 결과는 "정답"에 가까워서 모델 개선에 가장 도움이 돼요.

## 1. Apps Script 웹 앱 만들기 (5분, 한 번만)
1. https://script.google.com → **새 프로젝트**
2. 기본 코드를 지우고 `contrib/apps_script.gs` 내용을 붙여넣기 → 저장
3. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. **배포** → Google 계정 권한 허용 → 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`) 복사

## 2. 웹 페이지에 연결
`docs/config.js` 의 `CONTRIBUTE_URL` 에 위 URL을 넣고 커밋하면, 결과 화면에 "학습에 기여하기" 카드가 나타나요.

## 3. 모은 자료로 학습
Colab 노트북의 **"Drive 학습 자료로 학습"** 셀을 실행하면
`/content/drive/MyDrive/CleanPDF_학습자료` 를 읽어 모델을 미세조정하고, 새 `eraser.pt` / `eraser.onnx` 를 내려받을 수 있어요.
두 파일을 저장소에 올리면(`eraser.pt` → 루트, `eraser.onnx` → `docs/`) 웹 페이지가 새 모델을 사용합니다.

## 주의
- 시험지에는 다른 사람의 손글씨가 들어 있으니, 동의 문구를 지우거나 자동 전송으로 바꾸지 마세요.
- 웹 앱 URL은 페이지 코드에 공개되므로 누구나 요청을 보낼 수 있어요. 이상한 파일이 들어오면 폴더에서 지우면 됩니다.
