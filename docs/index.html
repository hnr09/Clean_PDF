결과

선택 · 학습에 기여하기

결과가 마음에 들거나 ✏️ 수정으로 고쳤다면, 이 결과를 AI 학습 자료로 보내 주세요. 다음 버전의 모델이 더 정확해져요. 보내는 것: 처리한 쪽의 원본 이미지 · 결과 이미지 · 지운 영역 (파일 이름·개인정보는 보내지 않아요).

도움말
  • 결과에서 ✏️ 수정을 누르면, 잘못 지워진 그림·그래프를 클릭 한 번으로 원본으로 되살리고, 남은 필기는 지우개 붓으로 지울 수 있어요.
  • 검정 펜 필기도 지워요. 필기가 글자를 완전히 덮은 곳은 AI가 주변 획으로 추정해서 채워요(틀릴 수 있음).
  • 처음 실행할 때 AI 모델(약 5MB)을 내려받아요. 컴퓨터에서 쪽당 몇 초~수십 초 걸려요. 크롬·엣지 최신 버전이면 GPU로 더 빨라요.
  • 결과가 아쉬우면 GitHub 저장소의 Colab 노트북으로 내 시험지에 맞춰 모델을 추가 학습할 수 있어요.
